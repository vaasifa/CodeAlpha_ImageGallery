# CodeAlpha_ImageGallery

## Project Description

This project is a responsive Image Gallery developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

* Responsive Image Gallery Layout
* Lightbox View
* Next and Previous Navigation
* Hover Effects and Smooth Transitions
* Mobile-Friendly Design

## Technologies Used

* HTML5
* CSS3
* JavaScript
